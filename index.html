    Warum ohne Ablaufdatum?

    Viele Gratis-Generatoren schreiben nicht deine Adresse in den Code, sondern einen eigenen Kurzlink. Läuft die Testphase aus, schalten sie ihn ab. Die gedruckten Flyer zeigen dann ins Leere.

    Mit Kurzlink

    1. QR-Code
    2. Kurzlink des Anbieters
    3. Deine Seite

    Der Anbieter steht dazwischen. Er kann den Link abschalten, kostenpflichtig machen oder Scans mitzählen.

    Hier

    1. QR-Code
    2. Deine Seite

    Nichts dazwischen. Der Code funktioniert, solange es deine Adresse gibt, auch ohne uns.

    Gut zu wissen

    Werden meine Eingaben gespeichert oder verschickt?

    Nein. Der Code entsteht in deinem Browser. Die Seite lädt keine fremden Dateien, setzt keine Cookies und zählt nichts mit. Schließt du das Fenster, ist alles weg.

    Läuft der Code wirklich nie ab?

    Der Code enthält deine Angaben direkt. Er funktioniert, solange zum Beispiel deine Webadresse erreichbar ist. Ziehst du auf eine neue Adresse um, brauchst du einen neuen Code.

    SVG oder PNG?

    SVG für Druckerei und Grafikprogramme, es bleibt in jeder Größe scharf. PNG für Word, E-Mails und soziale Netzwerke.

    Wie groß muss der Code gedruckt werden?

    Die Vorschau zeigt eine Mindestbreite. Als Faustregel gilt: Abstand zum Code geteilt durch 10. Wer aus 2 Metern scannen soll, braucht also etwa 20 cm.

    Welche Fehlerkorrektur passt?

    M passt fast immer. H lohnt sich, wenn der Code draußen hängt und verschmutzen kann. L macht den Code gröber, wenn sehr viel Inhalt hineinmuss.

    Ist das WLAN-Passwort im Code sicher?

    Wer den Code scannt, kennt danach das Passwort. Bei einem Gäste-WLAN ist das gewollt. Für dein internes Netz solltest du keinen Aushang machen.
